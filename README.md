# MR FOP FASHIONS — Phase 1

Premium responsive public website foundation for MR FOP FASHIONS COMPANY NIGERIA LIMITED.

## Stack
- React 18 + Vite
- Responsive CSS and Lucide icons
- Progressive Web App manifest and service worker
- GitHub Pages deployment using GitHub Actions

## Local development
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

## GitHub Pages
The Vite base path is configured for https://scholar94.github.io/mrfob/.
In repository Settings → Pages, select GitHub Actions as the deployment source.
The workflow in .github/workflows/deploy.yml builds and deploys the dist folder.

## Phase 1 scope
This phase implements the public-facing brand website, responsive layout, collection showcase, Fashion Institute introduction, WhatsApp enquiry link, PWA shell and deployment workflow.

Customer authentication, Firestore, order management, payments, Google Drive uploads and AI measurement are later phases and are not claimed to be operational yet.

Replace sample editorial photography with approved company-owned images before public launch. The official theme song will be connected after the company uploads the audio asset.

## Free-tier safeguards
No billing account or card is configured by this project. Review GitHub, Firebase and Google service quotas before production use. Never enable paid billing without the owner's explicit approval.
